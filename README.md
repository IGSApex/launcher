# SPT Launcher

Customized SPT launcher with server accounts, profiles, and client mod management.

## Features

- **Server accounts:** Log in or register when connecting to a server that requires launcher accounts.
- **Remember Login:** Save your login for a server so you can reconnect without entering credentials again. Uncheck it to stop remembering that login.
- **Profiles:** Create, select, and manage game profiles associated with your server account.
- **Mod Manager:** Open **Mod Manager** from the Profiles page to compare server-required client mods against your installed mods. Differences are highlighted.
- **Refresh:** Update the displayed server and local mod lists.
- **Update Mods to Match Server:** Download missing or different client mods from the server. Existing differing files are backed up before replacement; unrelated local mods are left alone.
